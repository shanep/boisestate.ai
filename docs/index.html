boisestate.ai for Claude Code
Quickstart How it works GitHub

Claude Code on your boisestate.ai account

Use Claude Code for your projects without an Anthropic account. Every request goes through boisestate.ai, so it comes out of your Boise State quota. Setup takes about 5 minutes.

Get started How it works macOS and Linux

What you need

macOS or LinuxOn Windows use WSL, which is Linux. I have not tested it there yet.
Node 22.3 or newerCheck with node --version.
A boisestate.ai API keyYou can make one in your boisestate.ai settings.
Claude CodeStep 1 installs it if you don't have it.

Setup

You only do this once. Open a terminal and work through the steps in order.

  1. 1

    Install Claude Code

    Skip this step if you already have it. You do not need to sign in to Anthropic, so don't run claude yet.

    Terminal
    $ curl -fsSL https://claude.ai/install.sh | bash
  2. 2

    Add the plugin

    The first command tells Claude Code where to find the plugin, and the second one installs it.

    Terminal
    $ claude plugin marketplace add shanep/boisestate.ai
✔ Successfully added marketplace: boisestate-ai
$ claude plugin install boisestate@boisestate-ai
✔ Successfully installed plugin: boisestate@boisestate-ai (scope: user)
  3. 3

    Install the boisestate command

    This puts a small boisestate command in ~/.local/bin. It finds the newest version of the plugin each time it runs, so plugin updates just work.

    Terminal
    $ node ~/.claude/plugins/cache/boisestate-ai/boisestate/*/dist/boisestate.cjs install
Installed /Users/you/.local/bin/boisestate

    If it also says ~/.local/bin is not on your PATH, add this line to the end of ~/.zshrc (macOS) or ~/.bashrc (Linux), then open a new terminal.

    ~/.zshrc or ~/.bashrc
    export PATH="$HOME/.local/bin:$PATH"
  4. 4

    Save your API key

    Paste your key when it asks. Nothing shows up while you paste, that is on purpose.

    Terminal
    $ boisestate login
boisestate.ai API key:
Saved the key to the macOS login keychain.

    Never paste your API key into a Claude chat, a commit or a file in your repo. Anything you type into Claude goes to the model and into the session history, and anyone with your key can spend your quota.

  5. 5

    Start coding

    Go to your project and run boisestate instead of claude.

    Terminal
    $ cd ~/my-project
$ boisestate

    The first time, Claude Code asks you to pick a color theme and then asks if you trust the folder. Make sure and pick Yes, I trust this folder. The default is No, which just exits.

    That's it! You are all setup. boisestate takes the same args as claude, so boisestate -c picks up your last conversation.

Watch your quota

Every message costs real money out of your monthly boisestate.ai quota. Each call to the model carries Claude Code's instructions and tool list, which is about 12,000 tokens before you type a word, so it adds up faster than you would think.

/clear between tasks

The whole conversation is sent again on every call. Start fresh when you switch to something new and each call stays small.

boisestate usage

Shows what you have spent this month, by model and by day. Inside a session, run /boisestate:usage.

Warnings at 80% and 100%

Claude Code shows a warning at the end of a turn when your spend crosses 80% and then 100% of the quota.

No auto mode

boisestate turns auto mode off. Its safety checks cost about 6 times more than the work itself, and they burned through a month of quota in under an hour.

The plugin's numbers are an estimate from its own log. The real numbers are on your boisestate.ai usage page.

Commands

CommandWhat it does
boisestateStart Claude Code on boisestate.ai
boisestate -cContinue your last conversation
boisestate -p "question"Ask one question and print the answer
boisestate usageShow this month's spend
boisestate statusShow where your key is saved and if the command is installed
boisestate loginSave or replace your API key
boisestate logoutRemove your saved key
boisestate --helpShow every command

Troubleshooting

boisestate: command not found

~/.local/bin is not on your PATH. Add the export PATH line from step 3 to your shell profile and open a new terminal.

It says no API key is saved

Run boisestate login and paste your key. Then run boisestate status to check where it went.

Claude Code wants me to log in

You ran claude instead of boisestate. Plain claude talks to Anthropic and needs an Anthropic account. Quit and run boisestate.

"Your boisestate.ai quota is used up"

You have spent this month's quota, and boisestate.ai refuses every call until it resets at the start of next month. There is nothing to fix on your end, so plan accordingly.

"The backend did not respond within its time limit"

boisestate.ai stops any single request after about 60 seconds. This mostly happens when you ask for a very large answer at once. Ask for smaller pieces of work, or just try again.

Linux: where did my key go?

On Linux the key goes in your keyring through secret-tool. If you don't have secret-tool, it goes in ~/.config/boisestate-ai/api-key, a file only you can read. To use the keyring on Ubuntu, install it and log in again:

Terminal
$ sudo apt install libsecret-tools
$ boisestate login
Updating the plugin
Terminal
$ claude plugin marketplace update boisestate-ai
$ claude plugin update boisestate@boisestate-ai
Removing everything
Terminal
$ boisestate logout
$ claude plugin uninstall boisestate@boisestate-ai
$ rm ~/.local/bin/boisestate
